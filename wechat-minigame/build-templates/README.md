# WeChat build templates

`wechatgame/game.json` is a custom Cocos build template.

It makes every WeChat build include the `chapter-jingwei` subpackage automatically, so a rebuild does not silently overwrite the subpackage configuration.

The AppID in `project.config.json` is still generated by Cocos and may fall back to the Cocos test AppID; run `tools/art/patch-wechat-build.mjs` after a build, or set the AppID in the Cocos WeChat build panel.
